БЫСТРЫЙ ПУТЬ ДЛЯ ANDROID БЕЗ ПК:
1. Загрузите ВСЁ содержимое проекта в корень GitHub-репозитория (не только папку app).
2. Откройте Actions → Build AI Studio APK.
3. Нажмите Run workflow (если workflow ещё не запустился автоматически).
4. После зелёной галочки откройте запуск и скачайте Artifact AI-Studio-4.0-debug-APK.
5. Распакуйте ZIP-артефакт и установите app-debug.apk на телефон.

ПУТЬ С WINDOWS:
Откройте папку проекта в Android Studio, дождитесь Gradle Sync, затем Build → Build APK(s).

Примечание: это Android APK-оболочка с встроенным текущим интерфейсом v3.0. Настоящие AI-модели не включены в APK и подключаются отдельно.
