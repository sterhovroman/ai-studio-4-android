# AI Studio Ultimate 4.0 — Android APK project

Это Android Studio-проект, который упаковывает веб-интерфейс AI Studio 3.0 в отдельное Android-приложение на базе Android WebView. После сборки устанавливается APK с собственной иконкой приложения (иконка лаунчера использует стандартную иконку Android, её можно заменить позже).

## Что входит
- Отдельное Android-приложение, не требующее открытия Chrome.
- Встроены HTML/CSS/JS-файлы AI Studio 3.0.
- Выбор фото и видео из памяти телефона через системный файловый диалог.
- Сохранение проектов и настроек в WebView localStorage.
- Загрузка экспортированных файлов через системный Download Manager.
- Возможность указать адрес собственного backend-сервера в настройках приложения.
- GitHub Actions workflow для автоматической сборки APK.

## Честный статус функций
В APK упакован текущий функционал версии 3.0: процедурные музыкальные наброски и WAV, базовая сборка ролика и WebM там, где WebView поддерживает MediaRecorder, фотофильтры/кадрирование/рисование и локальные проекты. Это не полноценные аналоги Suno, Topview или CapCut. Настоящая AI-генерация музыки/видео, AI-удаление фона и обработка объектов требуют подключения отдельных моделей и backend. Папка backend содержит мост-заготовку, а не готовые нейросети.

## Сборка на Windows или Linux через Android Studio
1. Установи Android Studio с официального сайта: https://developer.android.com/studio
2. Установи Android SDK Platform 35 и Android SDK Build-Tools через SDK Manager.
3. Распакуй архив проекта в отдельную папку.
4. В Android Studio выбери **Open** и укажи папку `AI_Studio_4_Android`.
5. Дождись Gradle Sync. Если Android Studio предложит установить недостающий SDK, согласись.
6. Выбери **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
7. После успешной сборки нажми **locate** в уведомлении. APK будет в `app/build/outputs/apk/debug/app-debug.apk`.
8. Перенеси APK на Android, открой его и разреши установку из этого источника, если Android спросит.

## Сборка через GitHub без компьютера
1. Создай репозиторий GitHub и загрузи в него всё содержимое этого проекта, сохранив структуру папок. `app/`, `backend/`, `.github/`, `build.gradle`, `settings.gradle`, `gradle.properties` должны находиться в корне репозитория.
2. Открой вкладку **Actions**. Workflow **Build AI Studio APK** запустится при push в main/master. Также можно выбрать workflow и нажать **Run workflow**.
3. Дождись зелёной галочки.
4. Открой завершённый запуск workflow, найди раздел **Artifacts** и скачай `AI-Studio-4.0-debug-APK`.
5. Распакуй скачанный ZIP и установи `app-debug.apk` на Android.

Если вкладка Actions не видна, открой Settings → Actions → General и проверь, что Actions разрешены для репозитория.

## Требования и ограничения
- Минимальная версия Android: API 23 (Android 6.0); целевая SDK 35.
- Для сборки нужен Android SDK Platform 35 и JDK 17.
- APK — debug-сборка для тестирования, не подписанный релиз для Google Play.
- Приложение открывает интерфейс локально из APK. Для обращения к backend укажи адрес сервера, доступный с телефона по сети. Backend должен быть настроен отдельно; не публикуй тестовый сервер без аутентификации и HTTPS.
- Разрешение `usesCleartextTraffic` включено для локального тестового backend по HTTP в домашней сети. Для публичного релиза его следует отключить и использовать HTTPS.
- Проект не содержит закрытых ключей подписи. Для публикации в Google Play нужна отдельная release-подпись.
